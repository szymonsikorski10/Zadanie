# Zadanie
Wstępne sprawdzenie danych zostało wykonane za pomocą krótkiego kodu SQL, po utworzeniu tabel i zaimportowaniu do nich danych z plików CSV, sprawdzono dane pod kątem występowania błędów. Po ich wykryciu, czyszczenie danych i tworzenie zestawienia odbyło się w excelu przy użyciu power query. Zestawienie i wnioski znajdują sie w zakładce o tej samej nazwie w pliku excela.
